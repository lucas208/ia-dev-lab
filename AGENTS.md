# AGENTS.md

## Sobre o projeto

Este projeto é um laboratório para praticar conceitos de desenvolvimento de software assistido por inteligência artificial.
O projeto utiliza Java e contém exemplos simples criados durante a realização da atividade.

## Comandos

- `javac Hello.java` -> compila o programa Hello.
- `java Hello` -> executa o programa compilado.

## Convenções de código

- Utilizar nomes de classes em PascalCase.
- Manter o código simples, legível e organizado.
- Utilizar apenas caracteres ASCII nas mensagens exibidas no console.
- Nos arquivos em `src/`, não adicionar dependências externas ou frameworks sem necessidade explícita.

## Não fazer

- Não alterar arquivos fora do escopo da solicitação.
- Não versionar arquivos gerados pela compilação ou configurações locais da IDE.
