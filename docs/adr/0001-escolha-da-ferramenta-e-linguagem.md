# ADR 0001 - Escolha da ferramenta e linguagem

## Contexto

Este projeto foi desenvolvido como parte de uma atividade prática sobre desenvolvimento assistido por inteligência artificial. Era necessário escolher ferramentas para desenvolver e testar os conceitos apresentados na disciplina.

## Decisão

Foi escolhida a linguagem Java por já estar disponível e configurada no ambiente de desenvolvimento.

A ferramenta de IA escolhida foi o Codex integrado ao IntelliJ IDEA, pois permite utilizar recursos de assistência por IA diretamente no ambiente de desenvolvimento utilizado no projeto.

## Consequências

A utilização dessas ferramentas permite realizar a atividade em um ambiente já conhecido, reduzindo o tempo necessário para configuração e permitindo concentrar o trabalho nos conceitos de desenvolvimento assistido por IA.
